# Titanic Survival Prediction

## Overview
ML model to predict Titanic passenger survival
using Random Forest Classifier in Python.

## Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn

## Model
- Algorithm: Random Forest Classifier
- Accuracy: 82%

## How to Run
1. Clone this repo
2. pip install -r requirements.txt
3. python titanic.py

## Results
- Accuracy: 82%
- Key finding: Gender was most important feature
